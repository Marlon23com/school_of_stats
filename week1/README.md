# Week 1 - Stata Coursework Project

## Overview
This week focused on a Stata-based data cleaning and basic descriptive statistics workflow. The project uses the group coursework data file and demonstrates how to import data, inspect variables, clean missing or duplicate records, and summarize key patterns.

## Main files
- `group A data_cw_Marlon_Makwara.do` - the main Stata script used for the project

## What the project covers
- Importing data into Stata
- Describing dataset structure and variable types
- Checking for missing values and duplicates
- Renaming variables for consistency
- Creating cleaned, analysis-ready data
- Producing summary statistical output

## Learning focus
This project introduces the foundations of data preparation and exploratory analysis using Stata before moving into more advanced modelling and visualization tasks in later weeks.
