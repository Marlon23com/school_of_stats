# Week 4 - Descriptive Statistics and Cross-tab Analysis

## Overview
This week focused on descriptive statistics, frequency distributions, and crosstab analysis using data prepared for statistical reporting. The outputs show a strong emphasis on summarizing data and presenting findings clearly.

## Main files
- `week4_pspp_data.csv` - raw dataset used for analysis
- `week4_pspp_data.csv.sav` - SPSS-compatible version of the dataset
- `Part B frequencies_que1.pdf` - frequency analysis output
- `Part B descriptive statistics_que2.pdf` - descriptive statistics output
- `Part C crosstabs eduLevel_by_satScore.pdf` - cross-tabulation output
- `answers.docx` - written responses and notes

## What the project covers
- Frequency tables
- Measures of central tendency and spread
- Descriptive statistics for quantitative variables
- Crosstabulation by educational level and score categories
- Statistical interpretation of findings

## Learning focus
This week strengthens the ability to produce clear, interpretable statistics and communicate results in a report-ready format.
