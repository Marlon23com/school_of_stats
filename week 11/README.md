# Week 11 - Excel Stock Data EDA

## Overview
This project focuses on stock market data analysis in Excel. The dataset appears to be used for exploratory data analysis of stock trends, price movement, and summary reporting.

## Main files
- `Week11_Excel_Stock_EDA.csv` - stock dataset used for analysis
- `Week11_Excel_Stock_EDA.csv.xlsx` - Excel workbook version

## What the project covers
- Importing stock data into Excel
- Reviewing price and trend patterns
- Cleaning and structuring raw stock data
- Producing exploratory analysis summaries
- Highlighting business or market insights from the dataset

## Learning focus
This week strengthens spreadsheet-based data analysis and practical EDA for business and financial datasets.
