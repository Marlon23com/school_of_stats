# Week 9 - Titanic Exploratory Data Analysis

## Overview
This week used a Python notebook to perform an exploratory data analysis on the Titanic dataset. The analysis focuses on survival patterns, passenger composition, and relationships between variables such as age, sex, class, and fare.

## Main files
- `week9_titanic_eda_data.csv` - Titanic dataset
- `Marlon Makwara Week 9.ipynb` - main notebook
- `week 9.ipynb` - alternative notebook version
- `Rota overlap for 28-7-25.xlsx` - separate schedule-related workbook

## What the project covers
- Loading and inspecting the dataset
- Checking dimensions and missing values
- Analysing survival rates
- Comparing passenger class, sex, and age distributions
- Visualising survival patterns with charts
- Exploring fare distributions and relationships
- Summarising key insights from the EDA

## Learning focus
This week strengthens Python-based exploratory analysis and data storytelling using seaborn, matplotlib, and pandas.
