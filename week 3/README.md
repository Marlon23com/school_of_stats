# Week 3 - R Markdown Data Analysis and Visualisation

## Overview
This week focused on R Markdown-based data analysis and visualisation. The project uses vehicle sales data and explores the relationship between price and factors such as age, urban proximity, and dealership density.

## Main files
- `Marlon Tinotenda Makwara R markdown DDay.Rmd` - main analytical script
- `R markdown Day 2.Rmd` - follow-up exercise and analysis notes

## What the project covers
- Importing Excel data into R
- Data inspection and summary statistics
- Correlation checks
- Scatter plots and histogram visualisations
- Linear regression modelling
- Non-linear model comparison
- Testing for heteroskedasticity and multicollinearity

## Learning focus
This project develops core statistical analysis and reporting skills in R, with emphasis on building regression models and interpreting model assumptions.
