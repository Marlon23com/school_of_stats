# School of Statistics Coursework Portfolio

This repository contains the coursework, datasets, analyses, and project outputs completed across multiple weeks of the statistics and data analytics programme.

The work includes:
- Stata and Excel data cleaning and analysis
- R Markdown reporting and visualisation
- SPSS statistics workflows
- Python-based data exploration and text analysis
- Dashboard-style business reporting

## Weekly Projects

- Week 1: Stata data cleaning and initial coursework analysis
- Week 2: Kenya conflict / AI modelling dataset exploration
- Week 3: R-based data visualisation and statistical modelling
- Week 4: Descriptive statistics, frequency tables, and crosstabs
- Week 5: Customer review text cleaning and sentiment-style analysis
- Week 6: Outlier detection and income/age distribution review
- Week 7: Contact dataset cleaning and spreadsheet reporting
- Week 8: SPSS statistical analysis and reporting
- Week 9: Titanic exploratory data analysis in Python
- Week 11: Excel stock data EDA and trend analysis
- Week 12: SPSS output and statistical reporting project
- Week 14: Sales dashboard dataset and dashboard-style analysis

Each weekly folder includes project files, supporting data, and work generated during that week.
