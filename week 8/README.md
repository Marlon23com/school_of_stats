# Week 8 - SPSS Statistical Analysis Project

## Overview
This week involved a statistical project using SPSS outputs and a large dataset. The project includes data import, output files, and reporting material generated from structured analysis in SPSS.

## Main files
- `final dataset.sav` - SPSS dataset
- `week8_data_2000rows.csv` - CSV version of the data
- `all stats.spv` - SPSS output file
- `Output1.spv`, `Output2.spv`, `Output3.spv` - additional output files
- `OUTPUT.pdf` - final report output
- `week8 insights.docx` - summary findings and interpretation
- `csv_file_import.tpf` - import settings file
- `Marlon Makwara week8 project.zip` - packaged project bundle

## What the project covers
- Importing data into SPSS
- Reviewing statistical summaries
- Running descriptive and inferential analysis
- Producing output tables and charts
- Writing analytical insights and managerial interpretations

## Learning focus
This week builds capability in SPSS-based reporting, with emphasis on producing professional results and communicating statistical findings in a polished format.
