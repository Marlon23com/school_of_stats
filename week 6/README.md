# Week 6 - Outlier Detection and Distribution Analysis

## Overview
This project explores how outliers affect summary statistics and distributions in a dataset. The analysis uses income and age variables to show before-and-after effects of filtering unusual observations.

## Main files
- `week6_dataset.csv` - dataset for analysis
- `Marlon Makwara week 6 r markdown file.Rmd` - main R script
- `Marlon-Makwara-week-6-r-markdown-file.html` - rendered report output

## What the project covers
- Importing a dataset into R
- Calculating Q1, Q3, and IQR bounds
- Identifying outliers using the IQR method
- Comparing original and cleaned data distributions
- Creating boxplots and histograms
- Reporting how outlier removal changes summary statistics

## Learning focus
This week focuses on data quality assessment and cleaning, with an emphasis on recognising and handling extreme values that can distort analysis.
