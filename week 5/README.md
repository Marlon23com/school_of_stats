# Week 5 - Customer Review Text Cleaning and Analysis

## Overview
This project focused on cleaning and analysing customer review text data using Python. The workflow includes text preprocessing, feature creation, and simple sentiment-style analysis based on product ratings.

## Main files
- `week5_customer_reviews.csv` - raw customer review dataset
- `week5_final_csv_dataset.csv` - cleaned/exported dataset used for analysis
- `Week 5 final.ipynb` - final notebook with completed analysis
- `Week 5 project.ipynb` - project notebook with exploratory work
- `week5 final v2.ipynb` - revised version of the final notebook

## What the project covers
- Loading and inspecting review data
- Identifying unique products and review counts
- Removing numbers, emojis, and special characters
- Lowercasing and cleaning text fields
- Creating a review length feature
- Categorising sentiment as Positive, Neutral, or Negative
- Summarising insights using product counts and review-length comparisons
- Basic visualisation of review patterns

## Learning focus
This week develops foundational skills in text preprocessing and exploratory analysis for customer feedback data, which is useful for sentiment analysis and data-driven product insights.
