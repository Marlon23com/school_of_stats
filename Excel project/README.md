# Excel Project - Sales and Spreadsheet Analysis

## Overview
This project folder contains Excel-based data work and a sales dataset used for spreadsheet analysis and reporting. It demonstrates practical Excel skills for handling business data and preparing summaries for decision-making.

## Main files
- `week3_sales_data.csv` - sales dataset used for analysis
- `Book1.xlsx` - Excel workbook
- `Marlon Makwara T completed tasks.xlsx` - completed Excel project workbook

## What the project covers
- Data import into Excel
- Cleaning and organising spreadsheet data
- Sales analysis using Excel tools
- Basic business reporting and tabular summaries

## Learning focus
This project builds essential spreadsheet and Excel analytics skills needed for business data reporting and quick data exploration.
